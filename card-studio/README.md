內建 398 張卡片與 792 張正反面卡圖。預設販售模式，可切回原交換模式。勾選可賣卡片、輸入數量與每張單價（NT$），下載 PNG 貼社團。未填單價維持空白並在表圖標示，不提供市場價。販售資料以 state.saleItems 儲存，交換資料仍使用 state.items，UID 與 v2 備份格式保持相容。

# 偶像卡片交換工作室

非官方、本機優先的卡片圖鑑與交換圖片工具。內建官方第 1～6 彈正反面圖庫；所有讓／求與備註僅存在使用者的瀏覽器。

## 使用

- 網頁版：在 GitHub Pages 開啟 `card-studio/`；點「下載離線圖庫」完整儲存正反面圖片。
- 單檔版：下載 Actions 的 `offline-card-studio` 成品，解壓縮後開啟 HTML，無網路依賴。
- 卡片可搜尋、篩選彈數／星等、翻面；交換圖輸出 PNG，支援 3／5 欄與單／雙邊。
- 自訂圖片用 `_front`／`_back` 檔名配對。清單可備份／合併還原。

## 更新圖庫

在 GitHub Actions 手動執行「更新官方卡片圖庫」。程式只抓公開資料，不需要帳密；重用已存在圖片，來源圖片更換時使用新的雜湊檔名。失敗時不覆寫上一版目錄，不刪除舊卡片。圖庫穩定 ID 使用官方資料 ID，與 OCR 卡號分開。

網頁版「檢查圖庫更新」先下載所有新圖，再切換圖庫；個人清單不重設。單檔離線版需下載新的成品。

本機開發：Python 3、Pillow。`python3 -m pip install -r requirements.txt`，執行 `python3 scripts/sync_catalog.py`、`python3 scripts/build_offline.py`，用 `python3 -m http.server` 預覽。

## 範圍與限制

只收錄官方公開卡表提供的卡片；活動卡、特殊印刷版本可能未包含。不憑空生成缺失背面。圖片僅縮放及 WebP 編碼，保留完整卡片邊緣。

卡號欄位可填補 OCR 無法辨識的結果。星等為官方資料；品牌、歌曲若無官方結構化資料則不推測。超長交換表會要求增加每排張數或減少選取張數。

原權利人保有卡片圖片與角色版權；來源逐卡記錄於 `data/catalog.json`，本工具不宣稱圖片授權或官方合作。

## 已核對的補充圖庫（2026-10-08）

本機版本收錄原官網 347 張及補充來源 51 張，共 398 張、792 張真實圖片。補充包括 28 張 P 版（其中 AP6-002P、AP6-003P 為隱藏造型，未見手寫簽名）、22 張活動卡及 1 張商品附卡。部分來源使用日文卡面，保留原圖，不推測台版卡面或正式卡號；活動名稱沿用來源標籤。

AP4-002P、店鋪賽參賽獎 2026/9月、店鋪賽報名獎 2026/9月、新生活應援發卡活動的來源背面是佔位圖。這 4 筆只收錄已核對正面，介面顯示「僅正面／缺背面」，不以普通版替代。

`data/supplemental-cards.json` 是已審核補充清單，`data/supplemental-review.json` 保留逐張核對、來源與雜湊紀錄。圖片以獨立檔名存放；更新官網時合併補充清單，不刪除已收錄補充卡。P 版用完整卡號固定 UID 並記錄普通版關聯；活動卡以來源活動標籤的固定雜湊作 UID。既有 official UID、瀏覽器資料庫及清單備份格式保持相容。

修改補充清單後，執行 `python3 scripts/merge_supplements.py`，再執行 `python3 scripts/validate_catalog.py`、`python3 -m unittest discover -s tests`、`python3 scripts/build_offline.py`。本次僅更新本機，尚未推送或公開部署。
