偶像卡片交換工作室 — 內建正反面圖庫版

離線包：用 Chrome／Edge 開啟「偶像卡片交換工作室.html」，無需連網或安裝。
網頁版：開啟 card-studio/，點「下載離線圖庫」，等進度完成後即可離線使用。

1. 用彈數、星等或關鍵字找卡片，點卡圖翻面。
2. 點「讓／求」選取卡片，填寫備註。
3. 工作台選雙邊／單邊、每排 3／5 張，下載 PNG。
4. 定期「備份我的清單」，換電腦可「還原清單」。
5. 自訂卡片可批次匯入。命名 AP6-001_front.png／AP6-001_back.png 可配對正反面。

圖庫來源為官方網站公開卡表。卡號經影像辨識的部分需對照實卡；未識別時顯示官方資料 ID，可自行補卡號。
正反面為官方獨立原圖，僅縮圖轉 WebP，未裁掉卡片邊框。
圖片與角色版權歸原權利人所有，本工具為非官方收藏整理用途。

清單保存在瀏覽器 IndexedDB。清除資料、無痕模式、搬移離線檔案或更換瀏覽器可能使原清單無法取得，請先備份。
備份包含個人選取狀態、備註與自訂卡片；官方圖庫由軟體提供，不重複包入個人備份。

更新方式：
GitHub Actions 執行「更新官方卡片圖庫」後，網頁版按「檢查圖庫更新」。
單檔離線版需要下載 Actions 產生的新離線包，原清單可透過備份還原。
開發者可執行 python3 scripts/sync_catalog.py 和 python3 scripts/build_offline.py。

彈數選單可選「活動／商品卡」。活動卡沿用来源的活動名稱識別。部分圖片為日文版本。

新版販售表：切到「販售表」，勾選可賣卡片，填數量（1–9999 的整數）與每張單價（NT$，0–999999.99，最多兩位小數）。價格未知保持空白，圖中會顯示「單價未填」。選每排 3 或 5 張，下載 PNG 表圖即可貼社團。只匯出勾選卡片；取消再勾選保留數量／單價。販售資料和交換讓／求獨立保存，備份包含兩者。販售表最長 16000 像素，超過請分批勾選匯出。沒有廣告、購物車、登入或付款。
